# Rock Paper Scissors

A simple Rock Paper Scissors game written in Python.

## Description

This is a console-based Rock Paper Scissors game where the player
competes against the computer.

The computer randomly chooses Rock, Paper, or Scissors, and the
program determines the winner based on the rules of the game.

The game also keeps track of the score between the player and
the computer.

## Features

- Rock, Paper, and Scissors choices
- Random choice for the computer
- Player vs. computer gameplay
- Score tracking
- Invalid input handling
- Option to exit the game

## How to Play

1. Run the program.
2. Choose one of the available options:
   - `1` - Rock
   - `2` - Paper
   - `3` - Scissors
   - `4` - Exit
3. The computer will randomly choose its move.
4. The program determines the winner.
5. The score is updated after each round.
6. Continue playing until you choose `4`.

## Rules

- Rock beats Scissors.
- Scissors beats Paper.
- Paper beats Rock.
- If both players choose the same option, it is a draw.
